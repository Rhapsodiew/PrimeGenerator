# 💰 PrimeGenerator

**PrimeGenerator** is a Go-based project that generates custom wanted posters featuring characters from the **One Piece** universe. The tool allows users to specify a character’s name, bounty, and other details, creating a unique, stylized wanted poster.

## 🚀 Features

- 🔤 **Customizable Text:** Set the character's name, bounty, and other details.
- 🖼️ **Generated Poster:** Output a high-quality image of a One Piece-style wanted poster.

## 🛠️ Tech Stack

- **Programming Language:** Go (Golang)
